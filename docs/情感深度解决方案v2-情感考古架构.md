# AI 小说情感深度解决方案 v2 · 情感考古架构

> 本版推翻 v1 的"规划式"思路，转向"挖掘式"。
>
> v1 的根本错误：把情感当"可规划的任务"——写前定 5 节拍张力曲线、硬约束命中锚点。结果只是更精致的程式化。
>
> v2 的核心认知：**情感不是被规划出来的，是被发现和加深的。** 好作品的情感张力是写完才浮现的，不是写前就画好的。文章是改出来的，情感也是。

---

## 一、为什么 v1 错了

你说得对。我重新想了一遍，v1 有三个根本性问题：

### 1. 把"结果"当"输入"

好小说的情感张力，是读者读完才感受到的东西。它是**结果**，不是**输入**。v1 试图在写之前就把"第3节拍张力8、用通感技法、命中雨声锚点"全规定好——这是把结果倒推成输入。真这么写出来，模型只是在填一张表，不是在写小说。

### 2. 情感是垂直深度，不是水平节拍

v1 的"5 节拍张力曲线"是水平展开的——一章里 5 段不同情绪。但真正的文学层次是垂直的：**同一段文字里多层情感并存**。

```
表层     她擦了三遍桌子，把抹布叠成方形。        ← 发生了什么
情感层   她在发麻。手指是机械的。                ← 当下情绪（v1 停在这里）
意层     如果那时拦了他一下。哪怕只是喊一声。     ← 没说出口的话
潜层     她在用"还有用"证明自己有资格留下。     ← 自己都没意识到的
韵层     "留下"与"被需要"——全书母题          ← 作者世界观渗透
```

越往下越藏，越藏越有力。v1 只做到了第二层（情感层），而且是用"约束"硬逼出来的——逼出来的情感必然虚假。

### 3. 约束扼杀生长

你说得最关键的这句："文章是改出来的，情感也是。可能我在某一章想表达的情感，会在前面进行梳理和写作过程中被重构。"

这意味着情感是**生长**出来的，有回溯、有修正、有意外发现。v1 的硬约束（"必须命中""必须达到"）锁死了生长空间——模型不能偏离蓝图，也就不能发现蓝图之外的东西。

## 二、v2 核心架构：种子 → 生长 → 考古 → 加深

```
写前：情感种子      ← 模糊、有歧义的入口，不规定情绪和技法
        ↓
写中：自由生长      ← 最少情感指令，让角色活在场景里，允许偏离
        ↓
写后：情感考古      ← 核心。多视角深度阅读，发现文字里已经藏着的隐藏层
        ↓
修：加深·藏回       ← 做减法 > 做加法。把浮在表面的压深，把过于明显的收回水线以下
        ↓
跨章：回溯重构      ← 后面考古发现的线索，可回溯加深前面章节
```

四个关键转变：

| v1（规划式） | v2（挖掘式） |
|-------------|-------------|
| 写前定 5 节拍张力曲线 | 写前只给一颗模糊种子 |
| 必须命中锚点、必须达到张力 | 让角色自由活在场景里 |
| 达标审查（打分 + 找薄弱节拍） | 情感考古（深度阅读 + 发现隐藏层） |
| 情感强化改写（做加法） | 加深·藏回（做减法优先） |

## 三、情感种子：写前只给一颗种子，不画蓝图

`generate_chapter_brief`（章节大纲）之后，新增一个极轻量的工作流 `generate_emotion_seed`。它不规定节拍、不指定技法、不设张力目标，只给三样东西：

```json
{
  "chapter_id": "...",
  "emotion_seed": {
    "core_tension": "一个人在被需要和被看见之间的裂缝",
    "scene_temperature": "湿冷的等待，时间在流走",
    "open_question": "她留下来的理由，是责任还是恐惧？"
  }
}
```

**三个字段的设计逻辑**：

- **`core_tension`（核心张力）**：一个模糊的、有人性歧义的命题，不是具体情绪。模型可以往任何方向生长——可以是压抑、可以是反抗、可以是自欺。给方向不给答案。
- **`scene_temperature`（场景温度）**：一个感官性的氛围暗示，不是指令。模型自然会往这个温度里写，但怎么用是它的事。
- **`open_question`（开放问题）**：一个本章可以触及但不一定要回答的问题。它像一颗没有解开的结，文字会不自觉地向它靠拢，但不需要"命中"。

**关键：没有 `must`、没有 `target`、没有 `technique`。** 种子是入口，不是蓝图。

## 四、自由生长的第一稿：把约束降到最低

这是对现有 `system_prompt_for_workflow` 的反向改造——**不是加情感指令，而是把已有的过度约束也松一松**。

现有的正文生成 prompt：
```
"必须参考 llmwiki 记忆、角色、大纲、时间线、伏笔、雷点..."
"尤其要读取 volume_memory 和 anti_repetition_notes，避免重复..."
```

这些是**事实约束**，保留。但 v1 想加的"必须命中情感锚点、必须达到张力8、必须用通感技法"——全部不要。

第一稿的 system prompt 只在事实约束之外，加一句**柔软的引导**：

```python
def system_prompt_for_workflow(workflow, emotion_seed=None):
    if workflow in {"generate_chapter_draft", "revise_selection"}:
        base = (
            "你是专业的中文长篇小说创作助手。当前任务是生成或改写小说正文。"
            "只返回可直接放入章节编辑器的中文正文。"
            "必须参考上下文中的记忆、角色、大纲、时间线、伏笔、雷点。"
            "尤其要读取 volume_memory 和 anti_repetition_notes，避免重复。"
        )
        if emotion_seed:
            base += (
                f"\n\n【本章的情感入口·不是约束，是你可以往任何方向生长的土壤】\n"
                f"核心张力：{emotion_seed['core_tension']}\n"
                f"场景温度：{emotion_seed['scene_temperature']}\n"
                f"一个可能触及的问题：{emotion_seed['open_question']}\n"
                f"你不必回答这个问题，也不必围绕张力来写。让角色活在场景里，"
                f"让情感从动作和细节里自己长出来。如果角色偏离了预期，允许它偏离。"
            )
        return base
    # ... 其他 workflow
```

**最后那句"允许偏离"是整个 v2 的灵魂。** v1 不允许偏离，所以写不出意外之喜。真正的文学性恰恰来自偏离——角色做出作者没预料的事，然后作者顺着重构。

## 五、情感考古：写后的多视角深度阅读（核心环节）

这是 v2 的心脏。写完一章后，不是"打分 + 找薄弱节拍"，而是做**三次独立的深度阅读**，每次切换一个视角，去发现文字里**已经藏着但还没被充分挖掘**的隐藏层。

### 5.1 三视角

**视角一：角色潜意识考古**

不分析情节，只盯着角色"没说什么"。

```
你是一个文学评论家，正在深度阅读这段小说文字。
不要分析情节，不要评价文笔。只做一件事：
盯着角色的动作、停顿、回避、反常行为，追问一个问题——
"这个角色自己都没意识到的，是什么？"

例如：
文字写"她擦了三遍桌子"——为什么是三遍？不是一遍不是两遍？
文字写"她把抹布叠成方形"——为什么是这个动作？她在控制什么？
文字写"她没接话"——她回避的到底是什么？

输出：潜意识线索清单
- 哪个细节其实藏着角色自己都没意识到的动机
- 哪个回避其实有深意
- 哪个反常行为是潜意识的泄露
每个线索标注：它在文字里的位置 + 你推断的潜意识内容 + 为什么
```

**视角二：读者体感考古**

切换到读者第一人称，不分析，只记录身体反应。

```
你是一个普通读者，正在读这段小说。
不要分析，不要评价。只做一件事：
逐段读下去，记录你"读到哪儿时心里动了一下"。

那个"动了一下"可能是：
- 突然觉得心疼
- 突然屏住呼吸
- 突然想骂人
- 突然觉得哪里不对但说不上来
- 突然觉得这句话有重量，但不知道为什么

输出：体感地图
- 情感共振点：哪句话让你动了，动了什么
- 情感断裂点：哪里你觉得该动但没动，哪里你觉得假
- 沉默点：哪里你停下来想了想，哪怕只有一秒
```

**视角三：母题回响考古**

跳出本章，站在全书高度看反复出现的东西。

```
你是一个正在重读自己作品的小说家。
你已经在写一本长篇，这是其中一章。
跳出这一章，回想全书——

有没有某个意象、某个动作、某句话，在前面章节也出现过？
如果有，它现在是什么意思？和之前一样吗？变了什么？
如果没有，这一章有没有自然地长出了一个新的、可能在后面回响的种子？

输出：母题回响地图
- 已有母题在本章的回响（哪里触及了、可以加深）
- 本章新生的意象种子（第一次出现，还不明显，但可能长成母题）
- 全书反复出现的"未解之结"（不回答，只标注本章有没有碰到它）
```

### 5.2 三视角汇合成"隐藏层地图"

三个视角的产出不是打分，是**勘探报告**——告诉你"哪里有矿"：

```json
{
  "chapter_id": "...",
  "subconscious_leads": [
    {"position": "第2段", "detail": "擦三遍桌子", "inferred": "用控制小动作压抑失控感", "depth": "可加深"},
    {"position": "第5段", "detail": "没接话", "inferred": "回避承认自己需要被需要", "depth": "可加深"}
  ],
  "reader_felt_map": {
    "resonance_points": [{"position": "第3段末", "felt": "心疼", "why": "动作太整齐了，整齐得像在撑着"}],
    "rupture_points": [{"position": "第6段", "issue": "该动但没动，情绪转折太突然"}],
    "silence_points": [{"position": "第4段", "note": "读者会停一下，但不知道为什么——这是好的留白"}]
  },
  "motif_echoes": {
    "existing_motifs": [{"motif": "留下/被需要", "chapter_touch": "第5段触及但浮在表面", "can_deepen": true}],
    "new_seeds": [{"image": "方形", "first_appearance": true, "potential": "可能长成控制欲的象征"}],
    "open_knots": [{"knot": "她留下来的理由", "chapter_bumped": true, "resolved": false}]
  },
  "deepen_opportunities": [
    "第2段的'擦三遍'已经是好种子，可以再压深——不要加字，反而删一个解释性的词",
    "第5段的回避可以藏得更深——让她的回避看起来像别的理由",
    "第6段断裂处不需要补情绪，需要在前面多留一个伏笔"
  ]
}
```

**这份地图的价值**：它不是告诉你"哪里不达标要重写"，而是告诉你"哪里已经有矿可以加深"。方向完全不同——一个是修补缺陷，一个是发现潜力。

## 六、加深·藏回：做减法优先

拿到隐藏层地图后，对正文做"加深"而非"重写"。新增工作流 `deepen_and_bury`。

核心原则：**做减法 > 做加法。**

### 6.1 三种操作

**加深（Deepen）**：把已经触及但浮在表面的潜台词再压深一层。
- 不是加更多情绪词，而是删掉解释性的话，让读者自己感到。
- 例："她在发麻。手指是机械的。" → 删掉"她在发麻"，只留动作，让动作本身的机械感传递麻木。

**藏回（Bury）**：把过于明显的情感外露收回水线以下。
- 例："如果那时拦了他一下。哪怕只是喊一声。" → 这句潜台词太直白了，等于把潜层翻到水面上。改成让这个念头通过一个不相关的动作泄露——比如她突然停下手，看了一眼门口，然后继续擦桌子。读者会感到不对，但说不上来。

**留白（Leave）**：有些地方不需要改，它已经是对的——那种"读者会停一下但不知道为什么"的留白，是文学性的最高形态。地图标注的 silence_points 不要动。

### 6.2 操作 prompt 示意

```
你拿到一份"隐藏层地图"，它指出了这段文字里已经藏着但可以再深的潜力点。
你的任务不是重写，是加深。原则：

1. 做减法优先于做加法。能删一个解释性词语解决的，不要加一整句。
2. 把浮在表面的潜台词压下去。已经说出来的潜台词不算潜台词。
3. 保留留白点。地图标注的 silence_points 是好的，不要填满。
4. 不要追求"更动人"，追求"更藏"。越藏读者越能自己感到。

只修改地图指出的位置，其他地方一个字不动。
返回修改后的完整正文 + 每处修改的说明（改了什么、为什么做减法/藏回）。
```

## 七、跨章回溯重构：情感是层层沉积的

这是你说"文章是改出来的，情感也是"的工程化落地。

### 7.1 机制

第 N 章考古时，可能发现一条**新的潜意识线索**——比如发现角色某行为的真实驱动力是"证明自己有资格留下"。

这条线索不只在第 N 章有效。它可以**回溯**：

```
第N章考古发现："留下/被需要"是角色的核心潜意识驱动
    ↓
回溯检索：前面哪些章节已经触及但没有展开这个主题？
    ↓
对那些章节做"加深"：在已经触及的细节上再压深一层
    ↓
效果：读者重读前面章节时，会发现原来伏笔早就在了
```

### 7.2 数据结构

```sql
-- 情感考古记录（每章每次考古一条）
CREATE TABLE emotion_archaeology (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    chapter_id TEXT NOT NULL,
    hidden_layer_map TEXT NOT NULL,  -- 第五节的结构
    archaeologist_view TEXT,         -- subconscious / reader / motif
    created_at TEXT
);

-- 跨章回溯线索（考古发现的、可回溯加深的线索）
CREATE TABLE emotional_leads (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    discovered_in_chapter TEXT NOT NULL,
    lead_content TEXT NOT NULL,       -- "角色用控制小动作压抑失控感"
    lead_type TEXT,                   -- subconscious / motif / open_knot
    source_chapters_can_deepen TEXT,  -- JSON数组：哪些前序章节已触及可加深
    deepened_chapters TEXT,           -- JSON数组：已经回溯加深过的章节
    status TEXT DEFAULT 'discovered', -- discovered / deepened / archived
    created_at TEXT
);
```

### 7.3 回溯加深工作流

```
当情感考古发现一条强线索时：
1. 用向量检索在已写章节里找"已触及但未展开"的位置
2. 列出候选回溯章节，让用户选择哪些要回溯加深
3. 对选中章节，在该位置做"加深·藏回"操作（第六节）
4. 标记该线索为已回溯加深
```

**这不是推翻重写，是层层沉积。** 每次回溯加深，都让前面的文字多一层重量。这正是"文章是改出来的"——不是大改，是在已有细节上磨出更深的光泽。

## 八、意象生长系统：不指定含义，让含义在使用中长出来

v1 的"感官锚点"（"用听觉通道的'雨声'承载'不安'"）是错的——它在写前就规定了意象的含义。真实文学里，意象的含义是在反复使用中**生长**出来的。

### 8.1 机制

系统不指定意象含义，只记录"意象出现史"：

```json
{
  "image": "雨声",
  "appearances": [
    {"chapter": 1, "context": "她第一次等他，下着小雨", "felt_meaning": "中性·等待"},
    {"chapter": 3, "context": "他走后那天下大雨", "felt_meaning": "开始和'失去'绑定"},
    {"chapter": 7, "context": "她听到雨声会停一下，自己不知道为什么", "felt_meaning": "无意识回响"}
  ],
  "current_resonance": "失去 + 无意识",
  "growth_potential": "可在高潮章让它彻底爆发或彻底消失"
}
```

**含义是回望出来的，不是预设的。** 第一次出现时雨声就是雨声；第二次情境赋予它含义；第三次它自己开始回响。

### 8.2 意象生长工作流

在 `extract_emotional_state`（章节定稿时）顺带做意象追踪：

```
扫描本章正文，识别可能成为意象的重复元素（动作、物件、声音、天气）：
- 如果是已有意象的新一次出现 → 记录本次情境，更新 felt_meaning
- 如果是新意象第一次出现 → 登记为种子，暂不赋义
不主动规定含义，只记录它在哪些情境里出现过。
含义由考古视角（5.1 视角三）来回望总结。
```

```
MVP 步骤：
```

## 十、和两个参考项目的关系

| 项目 | v1 怎么用 | v2 怎么用 |
|------|----------|----------|
| webnovel-writer 拆文 agent | ~~把拆出的模式做成蓝图~~ | 拆文产出的是"情绪链条发现"，和情感考古同构——都是"发现文字里藏着什么"。拆文可以看作是对**别人作品**做考古，情感考古是对**自己作品**做考古 |
| PlotPilot 张力心电图 | ~~升级为事前规划+事后校验闭环~~ | 张力评分保留作为**粗筛**——如果一章张力全场低于3，可能确实有问题。但它只是考古的一个很浅的入口，不是核心 |
| PlotPilot 定向修写 | ~~扩展为情感偏差触发修写~~ | 保留"不回滚"理念，但改"修写"为"加深"——不是改到达标，是压到更深 |

**关键区别**：两个项目都是"写完→评估→修缺陷"。v2 是"写完→发现→加深潜力"。方向相反。

## 附录：v1 与 v2 对照速查

| 维度 | v1（已废弃） | v2（本版） |
|------|-------------|-----------|
| 核心隐喻 | 建筑图纸（先画后建） | 考古挖掘（先有后现） |
| 写前 | 情感蓝图（5节拍+锚点+技法+硬约束） | 情感种子（3个模糊字段，允许偏离） |
| 写中 | 约束式生成（必须命中） | 自由生长（最少约束） |
| 写后 | 达标审查（打分+薄弱节拍） | 情感考古（三视角深度阅读+隐藏层地图） |

| 情感层次 | 水平（5段不同情绪） | 垂直（同段文字5层并存） |
| 失败模式 | 精致的程式化 | 可能过于松散，但可通过考古循环收敛 |
