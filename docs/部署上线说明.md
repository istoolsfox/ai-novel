# 部署上线说明

本项目当前采用 **FastAPI 后端 + Vue/Vite 前端 + SQLite 文件数据库** 的轻量部署方案。现在优先保证能在线访问、能配置模型、能启动托管生成；桌面打包保留为后续能力。

## 一、功能链路

托管生成入口会自动准备故事资产，然后启动章节生成任务：

```text
项目设定
  ↓
自动补齐章节大纲
  ↓
自动生成角色档案并写入 llmwiki
  ↓
自动生成角色关系并同步关系画布
  ↓
写入情感托管约束和 prompt skills
  ↓
启动九步章节管线
  ↓
每章定稿后写入时间线、关键记忆、章节衔接包
  ↓
下一章读取上一章衔接包，承接末尾状态、情感余波和未决钩子
```

前端“角色关系图”页面会读取 `character-profiles` 和 `character-relationships`，用 ECharts 呈现画布。llmwiki 中也会同步 `relationships/canvas.md`，便于模型读取。

## 二、本地开发

### 1. 启动后端

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
python -m uvicorn app.interfaces.main:app --reload --host 127.0.0.1 --port 8000
```

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

## 三、Docker 部署

仓库根目录已经提供：

```text
Dockerfile
docker-compose.yml
```

启动：

```bash
docker compose up -d --build
```

访问：

```text
http://服务器IP:8000
```

数据会保存在 Docker volume：

```text
ai_novel_data
```

其中包含：

```text
/data/app.db
/data/projects
```

## 四、模型配置

进入前端“设置”页面，填写 OpenAI 兼容接口：

```text
Base URL: https://你的模型服务/v1
API Key: 你的密钥
Model Name: 模型名称
Temperature: 可按需要配置
Max Tokens: 建议长文本模型设置较大
```

系统会通过后端请求：

```text
{base_url}/chat/completions
```

如果没有配置模型，系统会使用本地 stub 继续跑通流程，方便验证前后端、数据库和托管链路。

## 五、环境变量

| 变量 | 说明 | 默认值 |
|---|---|---|
| `AI_NOVEL_DATABASE_URL` | SQLite 数据库位置 | `sqlite:///backend/app.db` |
| `AI_NOVEL_PROJECTS_DIR` | 项目文件根目录 | 由后端默认路径决定 |
| `AI_NOVEL_MODEL_TIMEOUT_SECONDS` | 普通模型调用超时 | `90` |
| `AI_NOVEL_GENERATION_TIMEOUT_SECONDS` | 章节生成超时 | `600` |

Docker 中默认设置为：

```text
AI_NOVEL_DATABASE_URL=sqlite:////data/app.db
AI_NOVEL_PROJECTS_DIR=/data/projects
AI_NOVEL_MODEL_TIMEOUT_SECONDS=120
AI_NOVEL_GENERATION_TIMEOUT_SECONDS=900
```

## 六、上线建议

如果部署到云服务器，建议：

1. 使用 Docker Compose 管理服务。
2. 使用 Nginx 或平台自带反向代理绑定域名和 HTTPS。
3. 给 `/data` 做持久化备份。
4. 模型 API Key 只保存在后端项目配置里，不要写入代码。
5. 长章节生成建议使用支持较大上下文和较长输出的模型。

## 七、后续打包方向

当前不强制打包。后续可以继续使用已有 Tauri 方案：

```text
Vue/Vite 前端 → Tauri 桌面壳
FastAPI 后端 → PyInstaller sidecar
SQLite + 项目文件 → 本地数据目录
```

这样可以在部署版稳定后，再做桌面化分发。
